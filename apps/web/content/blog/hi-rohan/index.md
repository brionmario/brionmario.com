Hi Rohan,

Identity Server is blocking cross origin requests and you can use a CORS filter to whitelist your origin.

In this article ([https://medium.com/@brionmario/how-to-set-up-wso2-identity-server-user-portal-in-an-development-environment-d406d15ec703](https://medium.com/@brionmario/how-to-set-up-wso2-identity-server-user-portal-in-an-development-environment-d406d15ec703)), checkout the "Configuring Identity Server" section for the filter.

Once you add the CORS filter, restart the server and the issues should be resolved.
